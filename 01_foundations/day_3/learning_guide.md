## 🎯 Setup check-Jupyter Lab
### 💡 What is JupyterLab?
JupyterLab is an interactive, web-based development environment (IDE) used by data scientists, bioinformaticians, and developers to write code, run experiments, and analyze data in real time.

### 🎯 Why Use It?
- **Interactive Execution**: Run your code section by section (in "cells") and see immediate outputs without running the whole script.

- **Code + Documentation**: Combine executable Python code with Markdown text, notes, and equations in a single document (Notebook).

- **Built-in Visualization**: View graphs, plots, and dataset tables directly inside your notebook.

- **Flexible Interface**: Work with multiple tabs, split views, terminal windows, and files side by side.

- **Ideal for Data Science & Bioinformatics**: Perfect for inspecting DNA sequences, reading CSV files, and doing Exploratory Data Analysis (EDA).
